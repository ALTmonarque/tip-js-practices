## 4. Задание 1. Первый запуск в двух средах

Файл `hello.js` запущен двумя способами:

- в Node.js командой `node practice-01/js/hello.js`, вывод появился в терминале;
- в браузере через `index.html`, вывод появился во вкладке Console (на самой странице его нет).

Отличается последняя строка:

| Среда | Вывод последней строки |
|---|---|
| Node.js | `Тип document: undefined` |
| Браузер | `Тип document: object` |

**Объяснение.** `document` — это объект страницы, он есть только в браузере. В Node.js нет страницы, поэтому такой переменной нет, и `typeof` для необъявленного имени возвращает `"undefined"` без ошибки.

## 5. Задание 2. Типы данных и преобразования

Файл: `practice-01/js/types.js`.

| Выражение | Ожидание до запуска | Фактическое значение | Тип результата | Объяснение |
|---|---|---|---|---|
| `"8" + 2` | `"82"` | `82` (строка) | string | Если один операнд строка, `+` склеивает: число 2 превращается в `"2"`. |
| `"8" - 2` | `6` | `6` | number | Оператор `-` работает только с числами, поэтому строка `"8"` преобразуется в число. |
| `Number("8") + 2` | `10` | `10` | number | Строку преобразовали явно, дальше обычное сложение чисел. |
| `"12" > "3"` | `false` | `false` | boolean | Две строки сравниваются посимвольно: `"1"` идёт раньше `"3"`, поэтому `"12"` меньше `"3"`. |
| `12 === "12"` | `false` | `false` | boolean | Строгое сравнение учитывает тип: число и строка не равны. |
| `Number("")` | `0` | `0` | number | Пустая строка преобразуется в 0. Поэтому пустой ввод нужно проверять отдельно. |
| `Number("text")` | `NaN` | `NaN` | number | Из текста число получить нельзя, результат: «не число». |
| `Boolean("false")` | `true` | `true` | boolean | Любая непустая строка истинна, даже если в ней написано слово `false`. |
| `typeof null` | `"object"` | `object` | string | Историческая особенность языка: `null` для `typeof` даёт `"object"`. |
| `typeof NaN` | `"number"` | `number` | string | `NaN` относится к типу number, хотя означает «не число». |

Для двух последних строк различаются значение выражения (`"object"`, `"number"`) и тип этого значения: `typeof` всегда возвращает строку.

## 6. Задание 3. Сводка выполнения задач

Файл: `practice-01/js/progress.js`. Программа сначала проверяет данные (тип, конечность, целое число, границы), и только потом считает остаток, процент и статус. Процент выводится через `toFixed(1)`, а статус определяется по исходным количествам, а не по округлённому проценту.

| Проверка | Входные данные (total, completed) | Ожидаемый результат | Фактический результат | Итог |
|---|---|---|---|---|
| Обычный случай | `12, 5` | Осталось 7; 41.7%; В работе | Осталось 7; 41.7%; В работе | Пройдено |
| **Свой вариант 5** | `7, 2` | Осталось 5; 28.6%; В работе | Осталось 5; 28.6%; В работе | Пройдено |
| Задач нет | `0, 0` | Задач пока нет | Задач пока нет | Пройдено |
| Ничего не выполнено | `5, 0` | Осталось 5; 0.0%; Не начато | Осталось 5; 0.0%; Не начато | Пройдено |
| Всё выполнено | `5, 5` | Осталось 0; 100.0%; Завершено | Осталось 0; 100.0%; Завершено | Пройдено |
| Выполнено больше, чем есть | `5, 6` | Ошибка | Ошибка: выполнено больше задач, чем существует | Пройдено |
| Отрицательное | `-1, 0` | Ошибка | Ошибка: количество задач не может быть отрицательным | Пройдено |
| Дробное | `5, 2.5` | Ошибка | Ошибка: количество задач должно быть целым числом | Пройдено |
| Строка | `"5", 2` | Ошибка | Ошибка: количество задач должно быть числом, а не другим типом | Пройдено |
| Выше границы | `1001, 0` | Ошибка | Ошибка: общее количество задач не должно превышать 1000 | Пройдено |
| NaN | `NaN, 0` | Ошибка | Ошибка: недопустимое числовое значение (NaN или бесконечность) | Пройдено |

Деления на ноль нет: случай `0, 0` обрабатывается раньше, чем считается процент. После проверок в файле возвращены данные варианта 5 (`7, 2`).

## 7. Задание 4. План выполнения по дням

| Проверка | Входные данные (total, completed, limit) | Ожидаемый результат | Фактический результат | Итог |

| Дробный лимит | `5, 2, 1.5` | Ошибка | Ошибка: дневная норма | Пройдено |

| Лимит строкой | `5, 2, "2"` | Ошибка | Ошибка: дневная норма | Пройдено |

## 8. Задание 5. Отладка

Файл: `practice-01/js/debug.js` (в репозитории лежит **исправленная** версия).

**Исходный вывод (до исправления):**

```text
Выполнено: 32
Осталось: -24
Контрольная сумма: 6
```

**Исправленный вывод:**

```text
Выполнено: 5
Осталось: 3
Контрольная сумма: 10
```

| Ошибка | Что наблюдалось | Причина | Исправление | Результат после исправления |
|---|---|---|---|---|
| Обработка количества задач | `Выполнено: 32`, `Осталось: -24` | `completedText` и `additionalText` — строки. Оператор `+` их склеил: `"3" + "2"` дало `"32"`. Из-за этого дальше вычитание дало -24. | Явно преобразовать строки: `Number(completedText) + Number(additionalText)`, и `Number(plannedText)` для вычитания. | `Выполнено: 5`, `Осталось: 3` |
| Граница цикла | `Контрольная сумма: 6` | Условие `taskNumber < 4` не включает число 4: сумма была 1 + 2 + 3. | Заменить на `taskNumber <= 4`. | `Контрольная сумма: 10` (1 + 2 + 3 + 4) |

**Ход отладки в DevTools:** на строке вычисления `completedTotal` стояла точка останова. Через Scope было видно, что `completedText` и `additionalText` имеют тип string. После шага Step over `completedTotal` оказался строкой `"32"`. Внутри цикла наблюдались `taskNumber` и `controlSum`: цикл завершался при `taskNumber = 4`, не выполнив этот шаг.
